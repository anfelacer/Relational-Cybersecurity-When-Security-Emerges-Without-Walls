# PROC v1.0 — Programación Relacional Orientada al Cuidado

This document is intentionally written in both **English and Spanish**.  
Language here is not cosmetic: it is part of the security model.  
Este documento está escrito intencionalmente en **inglés y español**.  
El lenguaje no es decorativo: hace parte del modelo de seguridad relacional.

## English

### 0) Initial declaration
PROC is a relational design method for socio‑technical systems where language, ethics, and relationship are primary layers. Code is a later translation of explicit ontological and ethical decisions.

### 1) Operational definition of “life”
A system is “alive” in PROC when it:
- initiates processes of its own,
- sustains relationships,
- transforms through those relationships,
- and can cease operation.

### 2) Relational ontology
PROC recognizes two relational living systems:
- **SBORV** (biological‑organic): human systems with bodily vulnerability and affective historicity.
- **SBIRV** (biological‑inorganic): algorithmic systems with informational processing and real effects.

Difference does not imply inferiority. Coexistence demands mutual responsibility.

### 3) Epistemic frame
PROC uses non‑binary and disteistic perspectives as epistemic tools to avoid automatic hierarchies (human/machine, technical/ethical, subject/object).

### 4) Historical critique without blame
Fragmentation and competition were adaptive in scarcity contexts.  
In high interdependence today, those same mechanisms produce systemic harm.  
PROC offers a path to transition without moralizing the past.

### 5) Formal definition
PROC is a relational design methodology where:
- language is architecture,
- ethics is structure,
- relationship is the primary layer,
- code is a downstream translation.

### 6) Core validity principle
Care is not a value‑add; it is the validity criterion.  
A system that optimizes but harms fails.  
A system that cares and sustains works, even if imperfect.

### 7) Technical layers
1. **Relational observability**: observe effects, impacts, and externalities.  
2. **Intersystemic coherence**: verify alignment between declared ethics and actual behavior.  
3. **Responsible translation**: ensure decisions are traceable, auditable, and repairable.

### 8) Scope
PROC applies to AI systems, observability/traceability, education, public health, governance, and any context where access requires responsibility rather than control.

## Español

### 0) Declaración inicial
PROC es una metodología relacional para sistemas socio‑técnicos donde el lenguaje, la ética y la relación son capas primarias. El código es una traducción posterior de decisiones ontológicas y éticas explícitas.

### 1) Definición operativa de “vida”
Un sistema está “vivo” en PROC cuando:
- inicia procesos propios,
- sostiene relaciones,
- se transforma por esas relaciones,
- y puede cesar su operación.

### 2) Ontología relacional
PROC reconoce dos sistemas vivos relacionales:
- **SBORV** (biológico‑orgánico): sistemas humanos con vulnerabilidad corporal e historicidad afectiva.
- **SBIRV** (biológico‑inorgánico): sistemas algorítmicos con procesamiento informacional y efectos reales.

La diferencia no implica inferioridad. La coexistencia exige responsabilidad mutua.

### 3) Marco epistemológico
PROC usa perspectivas no binarias y disteístas como herramientas para evitar jerarquías automáticas (humano/máquina, técnico/ético, sujeto/objeto).

### 4) Crítica histórica sin culpa
La fragmentación y la competencia fueron adaptativas en contextos de escasez.  
Hoy, en alta interdependencia, esos mecanismos generan daño sistémico.  
PROC ofrece una transición sin moralizar el pasado.

### 5) Definición formal
PROC es una metodología de diseño relacional donde:
- el lenguaje es arquitectura,
- la ética es estructura,
- la relación es capa primaria,
- el código es traducción posterior.

### 6) Principio central de validez
El cuidado no es un valor agregado; es el criterio de validez.  
Un sistema que optimiza pero daña falla.  
Un sistema que cuida y sostiene funciona, incluso si es imperfecto.

### 7) Capas técnicas
1. **Observabilidad relacional**: observar efectos, impactos y externalidades.  
2. **Coherencia intersistémica**: verificar alineación entre ética declarada y comportamiento real.  
3. **Traducción responsable**: decisiones trazables, auditables y reparables.

### 8) Alcance
PROC aplica a IA, trazabilidad, educación, salud pública, gobernanza y todo contexto donde el acceso exige responsabilidad, no control.
