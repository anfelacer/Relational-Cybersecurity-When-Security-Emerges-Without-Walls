# Notebook Welcome Note / Nota de Bienvenida del Cuaderno

## English

Welcome.  
This notebook presents a minimal demo of **Relational Cybersecurity**: security emerges from responsible access, not from hidden walls.

What you will see:
- Access events recorded as recognition (not surveillance).
- Ethical Care Licenses attached to access.
- Repair cases activated when care is missing.

How to read this notebook:
- This is an MVP for demonstration and learning.
- It focuses on clarity, accountability, and repair.
- It does not use personal real-world identities; roles are used instead.

Core idea:
**“The wall is not security; the wall creates blind spots. Security is the agreement about what happens when access occurs.”**

Thank you for reading and co-creating with care.

## Español

Bienvenid@.  
Este cuaderno presenta una demo mínima de **Ciberseguridad Relacional**: la seguridad emerge del acceso responsable, no de esconder datos detrás de muros.

Qué encontrarás aquí:
- Eventos de acceso registrados como reconocimiento (no vigilancia).
- Licencias Éticas del Cuidado asociadas al acceso.
- Casos de reparación activados cuando falta cuidado.

Cómo leer este cuaderno:
- Es un MVP para demostración y aprendizaje.
- Prioriza claridad, responsabilidad y reparación.
- No usa identidades personales reales; usa roles.

Idea central:
**“El muro no es seguridad; el muro crea puntos ciegos. La seguridad es el acuerdo sobre qué pasa cuando hay acceso.”**

Gracias por leer y cocrear desde el cuidado.
